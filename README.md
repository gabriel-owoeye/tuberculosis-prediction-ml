# Predictive Model for Early Detection of Tuberculosis Using Machine Learning Approaches

**Project Type:** Undergraduate Research Project

## Project Overview

This project explores the application of supervised machine learning techniques for the predictive modelling and early detection of tuberculosis (TB).

The study uses a tuberculosis patient dataset to develop and compare classification models. It involves data preparation, exploratory data analysis, feature analysis, handling class imbalance, model training, and performance evaluation.

## Research Objectives

- Prepare and analyse tuberculosis patient data.
- Develop a binary TB diagnosis target variable.
- Apply machine learning classification techniques.
- Address class imbalance using the Synthetic Minority Over-sampling Technique (SMOTE).
- Evaluate and compare the performance of the selected models.
- Identify the best-performing model based on the evaluation results.

## Machine Learning Algorithms

The following classification algorithms were implemented:

1. Logistic Regression
2. Support Vector Machine (SVM)
3. Random Forest

## Methodology

The project follows these major stages:

1. Data collection and inspection
2. Data cleaning and preprocessing
3. Exploratory data analysis
4. Correlation analysis
5. Principal Component Analysis (PCA)
6. Feature preparation
7. Train-test splitting
8. Class imbalance handling using SMOTE
9. Model training and prediction
10. Model evaluation and comparison

## Evaluation Metrics

The models are evaluated using:

- Accuracy
- Precision
- Recall (Sensitivity)
- F1-score
- Specificity
- Error Rate
- False Acceptance Rate (FAR)
- False Rejection Rate (FRR)
- Area Under the ROC Curve (AUC-ROC)
